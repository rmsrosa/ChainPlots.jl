ChainPlots.NODE_PROPERTIES — Constant
NODE_PROPERTIES

Names of the properties stored for each neuron (node) of a ChainGraph.

  • :layer_number: Int with the layer the neuron belongs to, with 0 for the input layer, 1, …, n-1 for the hidden layers and n for the output layer of a chain with n layers;
  • :layer_name: String with the name of the layer, e.g. "Dense(2 => 5, σ)", or "input layer";
  • :layer_type: Symbol with the type of the layer, e.g. :Dense, :LSTM, :GRUCell, :Conv, or :input_layer;
  • :index_in_layer: Tuple with the position of the neuron within its layer, e.g. (i,) for the output of Dense(n => m) or RNN(n => m), or (i, j, c) for a two-dimensional convolutional layer, and so on;
  • :layer_center: Float64 with the vertical mid-point of the layer;
  • :loc_x, :loc_y: Float64 with the coordinates of the neuron in the plot;
  • :neuron_color: Symbol with the default color of the neuron, see NEURON_COLORS.

ChainPlots.RECURRENT_CELLS — Constant
RECURRENT_CELLS

Recurrent cells that process a single time step, returning (y, state).

Since a cell returns a tuple, a Flux.Chain cannot continue after it, so a cell is only accepted on its own or as the last layer of a chain.

ChainPlots.SEQUENCE_LAYERS — Constant
SEQUENCE_LAYERS

Recurrent layers that process a whole sequence at once (Flux ≥ 0.15).

ChainPlots draws them folded, as a single time step: a vector input of length in is fed to them as a sequence of length one, and their output is taken as a vector of length out.

ChainPlots.ChainGraph — Type
ChainGraph <: Graphs.AbstractGraph{Int}

Graph of the neurons of a neural network, as built by chaingraph, with one vertex per neuron and one edge per connection between neurons of consecutive layers.

A ChainGraph implements the Graphs.jl interface, so functions such as nv, ne, vertices, edges and neighbors work on it, and so do packages built on that interface, such as GraphPlot.jl. It is plotted with plot(cg), once Plots.jl or Makie.jl is loaded; see plotchain for the attributes of the plot recipes.

Use nodeprop and nodeprops to read the properties of a neuron (see NODE_PROPERTIES), and layer_dimensions and layer_names for the properties of each layer.

The fields of a ChainGraph are internal: the graph backend may change in a future release without notice.

ChainPlots.ModelLayers — Type
ModelLayers

Internal description of a model as a sequence of layers, which is what chaingraph works with, so that it supports models from different packages.

For each layer, it holds a function applying the layer to an array of Float32, used to infer the dimensions of each layer, a function applying it to an array of NeuralNumbers, used to infer the connections between neurons, and its name and type, such as :Dense.

ChainPlots.chaingraph — Method
chaingraph(m::Flux.Chain, input_data::Array) -> ChainGraph

Return a ChainGraph with the graph structure of the neural network m when applied to input_data.

Each vertex is a neuron of the network, and each edge connects a neuron to a neuron of the next layer that it affects. The properties of each neuron, listed in NODE_PROPERTIES, are read with nodeprop and nodeprops.

The recurrent layers RNN, LSTM, GRU and GRUv3 are drawn folded, as a single time step, when the input is a vector. If the input is a sequence of size (in, len), the graph has a neuron for each time step instead, with each time step connected to the same and the later time steps of the next layer; the plot recipe does not lay the time steps out separately, though. The recurrent cells (RNNCell, …) return a tuple (y, state), so they can only be the last layer of a chain.

The plot recipe for ChainGraph draws it, as in plot(chaingraph(m, input_data)); see also plotchain.

ChainPlots.plotchain — Function
plotchain([backend,] m, input = nothing; kwargs...)

Plot the topology of the neural network m, which is plot(chaingraph(m, input); kwargs...).

It works with Plots.jl and with Makie.jl, whichever is loaded, as in using Plots or using CairoMakie. If both are loaded, choose one by passing ChainPlots.PlotsBackend() or ChainPlots.MakieBackend() as the first argument.

m can be a Flux.Chain, a Lux.Chain, or a single layer. If the first layer accepts an input with arbitrary dimensions, such as a convolutional or a functional layer, an input must be given, either as an Array or as a Tuple with the dimensions of the input.

Any other keyword argument is passed on to plot, such as title with Plots.jl, or axis = (; title = "...") with Makie.jl, as well as the attributes of the plot recipe for ChainGraph:

  • connection_color: color of the connections;
  • neuron_colors = NEURON_COLORS: either a Dict from layer types to colors, as in NEURON_COLORS, or a color for all neurons;
  • neuron_shape = :auto: :auto for a marker depending on the type of the layer, or a marker shape for all neurons.

With Plots.jl, it returns a Plots.Plot; with Makie.jl, a Makie.FigureAxisPlot.

ChainPlots.NeuralNumbers.NeuralNumber — Type
NeuralNumber <: Real

NeuralNumber encodes the "state" of a neuron as an Int8.

The possible states are: * state = Int8(0) for a "cold", or "off", state, meaning it can be triggered by a signal but it has not yet been triggered. It works as a neutral element in any diadic operation. * state = Int8(1) for a "hot", or "on", state, meaning it has been triggered by a signal.

The aliases are * cold = NeuralNumber(Int8(0)) * hot = NeuralNumber(Int8(1))
